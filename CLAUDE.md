# CLAUDE.md — сайт конкурса профмастерства службы ЭРТОС

Прочитай это до любой работы с интерфейсом. Сначала прочитай `HANDOFF.md` (что строим и в каком порядке), затем этот файл (как это должно выглядеть).

## Главное правило дизайна

**Интерфейс уже утверждён заказчиком. Твоя задача — перенести его в код один в один, а не придумать заново.**

Эталон, в порядке приоритета:

1. `design-reference/src/prototype.html` — рабочий утверждённый прототип: вход → тестирование → админ-панель. Его HTML, CSS и JS — источник точных значений.
2. `design-reference/screenshots/*.png` — как каждый экран должен выглядеть на компьютере (1440×900) и на телефоне (390 px), снято с прототипа.
3. `design-reference/src/common.css` и `design-reference/tailwind/ertos-preset.js` — токены: цвета, скругления, тени, анимации.
4. `design/tokens.json` и `design/brand-book.md` — фирменный стиль ГК ОрВД (логотип, цвета Pantone, шрифты).

Если нужного экрана в эталоне нет, собирай его только из тех же элементов и значений. Не вводи новые цвета, скругления, тени, шрифты, отступы или стили кнопок.

## Нельзя

- Менять скругления: поля, кнопки, плашки — 12px; карточки — 24px (на телефоне 20px); крупные панели — 28px (на телефоне 22px); кнопка внутри поля — 8px. Никаких `rounded-md`, `rounded-lg` и т. п. из стандартной шкалы Tailwind — только `rounded-control`, `rounded-card`, `rounded-panel`, `rounded-sm` из пресета.
- Использовать цвета не из пресета: никакого `blue-500`, `slate-…`, `gray-…`, фиолетовых градиентов.
- Подменять шрифт. Везде DIN Pro (`font-din`), запасной — Arial. Не Inter, не Manrope, не системный шрифт.
- Брать иконки не из Phosphor и не в начертании `fill`. Не использовать эмодзи и символы вроде ✓, ×, →, ⏱ вместо иконок.
- Рисовать логотип заново или менять его. Только файлы из `design/logos/`.
- Добавлять рамки к карточкам: у карточек тень `shadow-card`, а не border.
- Ставить карточки с цветной полосой слева, бейджи с эмодзи и прочие шаблонные украшения.
- Добавлять на страницу входа второй и третий адрес GKOVD.RU: он один, в подвале.

## Нужно

- **Иконки:** `@phosphor-icons/react`, `weight="fill"`. Размеры уменьшены относительно стандартных примерно на 18%: в полях ввода 16px, в кнопках 14–16px, в плашках-акцентах 16–18px. В поле — серый `#8a90a3`, при фокусе поля — `brand-blue`.
- **Анимация иконок:** `morphicons` (`morphicons/react`, `<MorphIcon>`). Глаз ↔ перечёркнутый глаз в поле пароля. Серый кружок → синий кружок с галочкой при выборе варианта ответа. Phosphor на сетке 256 — используй `svgToIcon` или `fitIcon`.
- **Страница входа:** синяя панель `bg-brand-panel` с картой авиатрасс: сетка параллелей и меридианов, трассы, аэропорты с кодами ИКАО, радар с центром в UNKL, движущиеся отметки самолётов. Координаты и коды ИКАО — из `prototype.html` (блок `.airmap`). Порядок анимации появления: панель → оси и круги радара → аэропорты и трассы → строки заголовка → карточка формы → поля по очереди.
- **Поля ввода:** высота 50px, рамка `line-2`, фон `#fafbfd`. В фокусе — рамка `brand-blue`, фон белый, `shadow-focus`.
- **Основная кнопка:** высота 48–52px, `bg-brand-blue`, текст белый DIN Pro Bold 15–16px обычным регистром. При наведении — `#00649f` и `shadow-btn`.
- **Тестирование:** вариант «Карточки».
  - Две карточки ФАП: `bg-fap-38` и `bg-fap-178`, радар в углу, круглая белая кнопка со стрелкой.
  - Вопрос в белой карточке, варианты ответа — плашки 12px с буквой А/Б/В/Г слева и морф-кружком справа.
  - Прогресс `bg-progress`, номера вопросов — квадраты 30px со скруглением 8px.
- **Админ-панель:** вариант «Аналитика».
  - Матрица «участники × вопросы»: клетка — сама иконка Phosphor fill. `check` в `brand-blue` — верно, `x` в `#e0444b` — неверно, серая клетка — нет ответа.
  - Справа карточки «Ответ участника», «Самые сложные вопросы», «Средний балл по филиалам». Разбор всех ответов участника — выдвижная панель справа со скруглением 24px.
- **Доступность:**
  - Все анимации отключаются при `prefers-reduced-motion`.
  - Текст на белом — не светлее `ink-2`.
  - `brand-light-blue` и `brand-gray` не использовать для мелкого текста.
  - Кольцо фокуса видно на каждом интерактивном элементе.
- **Адаптив:** перестройка на ширине 900px. Синяя панель уходит наверх, карточки ФАП встают в один столбец, отступы 12–16px.

## Как проверять

После каждого экрана:

1. Запусти dev-сервер.
2. Сними скриншот Playwright 1440×900 и 390×844 с `deviceScaleFactor: 2`.
3. Положи его рядом с соответствующим файлом из `design-reference/screenshots/` и сравни: отступы, размеры, скругления, цвета, иконки, шрифт.
4. Расхождения исправь до перехода к следующему экрану.
5. Если отклонение от эталона действительно нужно, сначала спроси заказчика.

## Шрифт и лицензия

DIN Pro лежит в `design/fonts/` (woff2). Лицензия ограничивает распространение. Не коммить шрифты в публичный репозиторий; для веба нужна веб-лицензия — по словам заказчика, организация её оформит.
