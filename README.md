# Прототип сайта конкурса профмастерства службы ЭРТОС

Утверждённый HTML-прототип: вход → тестирование (вариант «Карточки») → админ-панель (вариант «Аналитика»).

## Онлайн-просмотр

https://voropaevvladimir.github.io/ertos-contest-prototype/

## Запуск

Откройте `design-reference/src/prototype.html` в браузере (лучше через локальный сервер, например `python3 -m http.server` из корня репозитория). Любой логин и пароль открывают тестирование, логин `admin` — админ-панель.

## Шрифт

Шрифт DIN Pro лежит в `design/fonts/`. Права на веб-использование принадлежат владельцу лицензии; лицензия организации будет добавлена позже.

## Состав

- `design-reference/src` — прототип и варианты экранов
- `design-reference/tailwind` — пресет Tailwind с токенами
- `design-reference/screenshots` — эталонные скриншоты экранов
- `design/logos` — логотипы

Вопросы в прототипе — примеры, не утверждённый банк.

## Данные карты на экране входа

Карта декоративная. Коды ИКАО аэродромов сверены по открытым базам. Линии между аэродромами показывают реальные регулярные авиалинии: пары аэропортов взяты из базы маршрутов [OpenFlights](https://openflights.org/data) (лицензия ODbL, данные около 2014 года) и дополнены рейсами КрасАвиа из Красноярска (Богучаны, Туруханск, Игарка, Тура, Ванавара). Это не трассы ОВД из AIP России, и точность координат стилизована.
